# 明睿杰 · 个人简介

可自定义、可编辑的个人简介网页，基于 GitHub Pages 发布。

## 功能

- 单文件自包含（`index.html`），无任何构建依赖，打开即用
- 页面右下角 / 右上角「编辑资料」：在浏览器内直接编辑全部内容，自动保存到本机（localStorage）
- 支持导出 / 导入 JSON 备份、一键恢复默认内容
- 深浅色主题切换、响应式布局（桌面 / 平板 / 手机）

## 自定义内容

**方式一（推荐，改默认内容）**：编辑 `index.html` 顶部的 `CONFIG` 对象（姓名、技能、经历、项目等），提交后重新部署即可，所有访客都会看到新内容。

**方式二（仅本机预览）**：打开页面点击「编辑资料」修改并保存，再点「导出 JSON」备份；要让线上访客看到修改，需把导出的 JSON 同步进源码 `CONFIG` 或发给我代为更新。

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需服务器。

## 发布

```bash
git add -A
git commit -m "update profile"
git push
```

推送后 GitHub Actions / Pages 自动构建，约 1 分钟内生效。
